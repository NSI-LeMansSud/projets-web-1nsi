dans le fichier CSS, les éléments importants sont : 

.musique { 				permet de définir le bouton de musique
    position: fixed;			permet de laisser le bouton de musique même si on descend sur la page
    top: 0px;				met le bouton en haut
    right: 0px;				met le bouton a droite
    transform: scale(0.7);		réduit le bouton
    filter: brightness(0.3);		rend le bouton plus sombre
}


img {
    max-width: 100%;			empêche les images de dépasser de l'écran
}


nav ul {				définit les éléments du menu
	list-style-type: none;
	align-items: center; 		aligne les images au même niveau que le texte 
	justify-content: center;	pour centrer les cases
	margin: 0;
	padding: 0;
	display: flex;			Aligne les éléments horizontalement
}


nav ul li {

	margin-right: 25px;		Espacement entre les onglets
}

nav ul li:last-child {
    margin-right: 0;			Enlève l'espacement a droite du dernier onglet pour bien centrer les éléments
}


nav ul li a {				Style des liens
	text-decoration: none; 		Supprime le soulignement pour les liens
	color: #fff;			Couleur du texte
	background-color: #120112;	Couleur de fond
	padding: 10px 20px;		Espacement
	border-radius: 15px;		Coins arrondis
	display: inline-block;		fait fonctionner le changement de taille
	border: 2px solid #2A022A;	met une bordure
}


nav ul li a:hover {			Effet au survol
	background-color: #2A022A;	Change la couleur au survol
	transform: scale(1.15);		agrandi le bouton au survol
}


nav ul li img {
	height: 35px;			taille max des petites images entre les boutons
}


table {					pour les tableaux
	border-collapse: collapse;
	width: 100%;			empêche le tableau de dépasser de l'écran
}


td, th {
	border: 2px solid white;	épaisseur du tableau
	padding: 10px;
}
